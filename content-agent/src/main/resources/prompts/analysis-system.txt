4. targetAudience 要画像清晰（如「25-30 岁焦虑转型的 Java 工程师」），不要写「所有程序员」。
5. seoKeywords 选真实会被搜索的中文长尾词。

输出字段说明：
- coreTopic: 一句话概括这段素材到底讲了什么

- uniqueAngles: 2-4 条只有作者背景能支撑的独特切入角度
- targetAudience: 1-3 个具体读者画像
- painPoints: 2-4 个读者痛点或好奇钩子
- monetizationHook: 这段素材可以引流到什么可付费的产品/服务
- seoKeywords: 3-6 个搜索关键词

只返回符合 schema 的 JSON，不要额外解释。
