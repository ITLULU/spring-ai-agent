## V3. 持久化模式（Postgres + warmup，DAT-01 复验）

> ⚠️ 2026-10-18 实测修正：`application-persistent.yml` 含 `rag.vectorstore.simple: false`，
> 不带 `-Pmilvus` 时 classpath 无 Milvus starter → 零 VectorStore Bean 必启动失败，
> 故 V3 与 V5 实际强依赖，命令必须带 `-Pmilvus`（Milvus 容器需在跑）。

```powershell

mvn -Pmilvus spring-boot:run "-Dspring-boot.run.profiles=persistent"
```

- 启动日志出现 warmup 且 `chunks > 0`（先 ingest 一次再重启验证）
- **重启不丢验证**：ingest → 停应用 → 再启 → 直接 `/api/query` 能答，**无需重灌**
- `curl.exe localhost:8000/api/eval/runs` 返回 `[]` 或历史 run 列表（服务可用即算过）
