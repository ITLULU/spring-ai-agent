# 开发环境搭建清单（个人 Windows 电脑 · 无服务器 · 无 GPU）

> 原则：**凡是能用托管 API 解决的，一律不装**；基建（Milvus 等）全部走 Docker Desktop。
> 每一阶段只在需要时装对应的东西，不要第一天全装完。
> 本清单中大部分安装都可以直接让 Qoder/AI 工具代执行，卡住时把报错原文贴给它。

## 一、现在就装（阶段 1 第 1 周用）

| # | 软件 | 用途 | 要求/说明 |
|---|------|------|-----------|
| 1 | **JDK 21** | rag-kb 运行 | Temurin 或 Corretto 均可，设置 `JAVA_HOME`；验证 `java -version` 显示 21 |
| 2 | **Maven 3.9.x** | 构建 | 验证 `mvn -v`；国内建议在 `~/.m2/settings.xml` 配阿里云镜像（装不动就把报错给 AI 工具） |
| 3 | **Git** | 代码托管（里程碑要挂 GitHub） | 装完注册 GitHub 账号，配好 SSH key |
| 4 | **IDE** | 写代码 | IntelliJ IDEA Community 够用（或继续用 Qoder + Java 扩展） |
| 5 | **Docker Desktop** | 跑 Milvus / 各类中间件 | Windows 上需先启用 WSL2：管理员 PowerShell 执行 `wsl --install`，重启后装 Docker Desktop，Settings→Resources 内存分配 ≥ 8GB（Milvus standalone 约占 4GB） |
| 6 | **LLM API Key** | Chat + Embedding + Rerank | 见下方"模型 API"一节，**这是无 GPU 的核心替代方案** |

> 注：你这台机器已确认有 JDK 21.0.7 + Maven 3.9.10 ✅，缺 Docker、Git、IDE（台式机按上表补齐即可）。

## 二、模型 API（代替本地 GPU 的关键）

不需要任何 GPU，也不需要自己部署模型。注册一个平台的 key 就能覆盖 chat/embedding/rerank 全部需求：

| 平台 | 提供 | 免费额度 | 适合 |
|------|------|----------|------|
| **阿里云 DashScope**（兼容 OpenAI 接口） | qwen-plus / text-embedding-v3 | 新用户各模型 100 万 token | 默认推荐，rag-kb 的 `application.yml` 默认就指向它 |
| **硅基流动 SiliconFlow** | bge-reranker-v2-m3、bge-m3 embedding、各类 chat 模型 | 注册送额度 | **Rerank 专用**：脚手架里 `rag.rerank.enabled=true` + 它的 /rerank 地址即可，零部署 |
| DeepSeek | chat | 便宜 | 备选 chat 模型 |

配置方式就是 4 个环境变量（PowerShell）：

```powershell
$env:AI_API_KEY  = "sk-xxx"
$env:AI_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode"   # 或硅基流动
$env:AI_CHAT_MODEL    = "qwen-plus"
$env:AI_EMBED_MODEL   = "text-embedding-v3"
```

## 三、按需装（阶段 1 第 3 周起）

| 软件 | 触发条件 | 安装方式 |
|------|----------|----------|
| **Milvus** | 第 3 周切向量库时 | **不用单独装**——`rag-kb/docker-compose.yml` 已写好，`docker compose up -d` 即起 |
| TEI + bge-reranker（本地精排） | 可选，仅当想体验"本地部署 rerank" | 同样在 docker-compose 里（已注释的 rerank 服务）。⚠️ CPU 跑很慢，建议直接用硅基流动托管 API，这个跳过 |
| **Elasticsearch**（可选） | 想对比"手写 BM25 vs 工业级 BM25"时 | `docker compose` 加一个服务即可，非必需 |

> 内存提醒：16GB 内存的机器同时开 Docker Desktop(8GB) + IDEA + 浏览器会很紧。Milvus 容器不用时就 `docker compose stop`。8GB 内存机器建议全程用内置 SimpleVectorStore，效果评测不受影响。

## 四、阶段 2 需要（第 5 周起）

| 软件 | 用途 | 说明 |
|------|------|------|
| 关系数据库 | 工单状态机持久化 | **零安装方案：H2 内存库**（Spring Boot 加一个依赖就行）；想用 MySQL 就 `docker run` 一个容器 |
| **Node.js 18+**（可选） | 写 MCP Server | 官方 MCP SDK 以 TS/Python 为主；也可纯 Java（Spring AI 1.1 自带 MCP Server 支持，可完全不装 Node，二选一） |
| API 调试 | 测 Agent 工具调用 | IDEA Ultimate 自带 HTTP Client，或 Community 装 RestfulTool 插件；Postman 也行 |

## 五、阶段 3 需要（第 9 周起）

| 软件 | 用途 | 说明 |
|------|------|------|
| **Python 3.11+** | 读懂 LangChain/RAGAS、跑评测对照 | 推荐装 **uv**（一个命令装好 Python + 虚拟环境）；不需要 PyCharm，VS Code 够用 |
| 云 GPU 租用 | LLaMA-Factory LoRA 微调 Demo | **不用装任何东西**：AutoDL/矩池云按小时租（RTX 4090 约 2 元/h），网页里操作，跑 3-4 小时够用，全程 AI 工具带跑 |

## 六、验证清单（装完自测）

```powershell
java -version    # 21.x
mvn -v           # 3.9.x，Java version 显示 21
git --version
docker info      # 能列出 Server 信息 = Docker Desktop + WSL2 正常
cd rag-kb; mvn -q compile   # 脚手架在你的机器上编译通过
```

全部通过后，第 1 周任务就可以直接开工：`mvn spring-boot:run` → 按 README 的三个 curl 跑通入库→问答→评测。

## 七、明确**不需要**的

- ❌ 服务器/云主机（面试不考运维，本地 + 托管 API 足够）
- ❌ 本地 GPU / 模型部署（vLLM、Ollama 大模型等一律跳过；体验流程用云租）
- ❌ Kafka / K8s / 微服务基建（12 周内用不到，别让"顺便学一下"挤掉主线）
- ❌ LangChain4j（已决策选 Spring AI，它只出现在面试口头对比里）
